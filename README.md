# Nightjar

Downloads, support pages and privacy policy for **Nightjar**, a macOS menu bar
app that keeps a Mac awake — and says so when macOS ignores it.

The site is served by GitHub Pages at <https://azun-k2.github.io/nightjar/>:

| Page | URL |
|---|---|
| Home | <https://azun-k2.github.io/nightjar/> |
| Support | <https://azun-k2.github.io/nightjar/support.html> |
| Privacy policy | <https://azun-k2.github.io/nightjar/privacy.html> |

The last two are the support and privacy policy URLs given to App Store
Connect, so their paths should stay put.

This repository also carries the releases of **Nightjar Lid**, the free helper
that allows keeping the Mac awake with the lid closed. The landing page links
to `releases/latest/download/Nightjar-Lid.zip`, so that asset name should stay
put too.

The source lives in a separate private repository; only the downloads and the
site are public.

Support is by email: <khangazun@gmail.com>. Every mail link on the site opens a
message with a template already in it.
